================================================================================
CÁCH 1: KHỞI CHẠY BẰNG DOCKER (KHUYÊN DÙNG NHẤT - 1 CHẠM)
================================================================================
Yêu cầu: Máy đã cài đặt Docker và Docker Compose (ví dụ: Docker Desktop).

Bước 1: Mở Terminal / PowerShell tại thư mục gốc của dự án.

Bước 2: Tạo file cấu hình môi trường cho Backend:
  - Trên Windows (PowerShell):
      copy backend\.env.example backend\.env
  - Trên Linux / macOS:
      cp backend/.env.example backend/.env

Bước 3: Khởi chạy toàn bộ hệ thống bằng 1 lệnh duy nhất:
      docker compose up -d --build

Bước 4: Mở trình duyệt và truy cập: http://localhost:3000

* Để dừng hệ thống:
      docker compose down

================================================================================
CÁCH 2: KHỞI CHẠY THỦ CÔNG TRÊN MÁY (DÀNH CHO LẬP TRÌNH VIÊN)
================================================================================

--- PHẦN 1: KHỞI CHẠY BACKEND (FASTAPI) ---
Yêu cầu: Python >= 3.12 (khuyến khích dùng công cụ `uv` để cài nhanh: https://docs.astral.sh/uv/)

Bước 1: Mở Terminal, di chuyển vào thư mục backend:
      cd backend

Bước 2: Tạo file cấu hình môi trường:
      # Windows (PowerShell):
      copy .env.example .env
      # Linux / macOS:
      cp .env.example .env

Bước 3: Cài đặt thư viện dependencies:
      # Cách nhanh nhất (nếu có uv):
      uv sync

      # Hoặc dùng python venv truyền thống:
      python -m venv .venv
      # Kích hoạt môi trường ảo:
      #   Windows: .venv\Scripts\activate
      #   Linux/macOS: source .venv/bin/activate
      pip install -e .

Bước 4: Khởi động máy chủ Backend:
      # Dùng uv:
      uv run uvicorn detect_ai.main:app --host 0.0.0.0 --port 8000 --reload

      # Hoặc khi đã activate .venv:
      uvicorn detect_ai.main:app --host 0.0.0.0 --port 8000 --reload

* LƯU Ý: Mặc định backend sử dụng CSDL SQLite tự động tại `backend/data/detect_ai.db`.
  Hệ thống sẽ TỰ ĐỘNG tạo cấu trúc bảng và TỰ ĐỘNG nạp 3 tài khoản dùng thử ở Mục I
  ngay khi bạn khởi chạy lần đầu tiên. Không cần chạy lệnh tạo DB thủ công!


--- PHẦN 2: KHỞI CHẠY FRONTEND (NEXT.JS) ---
Yêu cầu: Node.js >= 18.18 (khuyến khích Node 20 LTS) và npm.

Bước 1: Mở một cửa sổ Terminal MỚI, di chuyển vào thư mục frontend:
      cd frontend

Bước 2: Tạo file cấu hình môi trường:
      # Windows (PowerShell):
      copy .env.example .env.local
      # Linux / macOS:
      cp .env.example .env.local

Bước 3: Cài đặt các gói thư viện:
      npm install

Bước 4: Khởi động giao diện phát triển:
      npm run dev

Bước 5: Mở trình duyệt và truy cập: http://localhost:3000
        Đăng nhập với các tài khoản được cung cấp ở Mục I.

--------------------------------------------------------------------------------
III. LỆNH KIỂM THỬ CHẤT LƯỢNG (TESTING & QUALITY CHECK)
--------------------------------------------------------------------------------
1. Chạy toàn bộ 145 bài test backend:
      cd backend
      uv run pytest tests -v

2. Kiểm tra tính toàn vẹn kiến trúc Clean Architecture:
      cd backend
      python scripts/check_bounds.py

3. Kiểm tra TypeScript & ESLint frontend:
      cd frontend
      npm run lint

4. Thử nghiệm đóng gói build frontend cho Production:
      cd frontend
      npm run build
